# Camera Hand Gesture Recognition

## Goal

Merge the `hand-gesture-recognition` project that reads a JPG static image, runs the inference and detects the known hand gesture from the pre-trained model with the `simple-camera` project that reads the camera sensor and display the image on the LCD.

The merged application should be able to replace the JPG image with the hand gesture with the camera frame and detect the hand gesture from the camera.

## Prerequisites

- Both `hand-gesture-recognition` and `simple-camera` should be working (building with no errors).
- This project must be for the ESP-IDF v5.5.x.
- This project will run on the ESP32-S3-EYE development kit.
